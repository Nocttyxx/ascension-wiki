V1.0.0 — Centre de commande

Commandes officielles

Toutes les commandes publiques sont regroupées sous /ascension. Les outils admin exigent les permissions opérateur.

GroupeCommandeUtilité
Public/ascensionOuvre le menu général.
Public/ascension aideAffiche toutes les commandes publiques.
Public/ascension versionAffiche la version officielle, Minecraft, Forge et Vaelorn.
Public/ascension statutRésumé complet de la progression personnelle.
Public/ascension classeConsulte ou choisit la discipline.
Public/ascension factionConsulte ou choisit la faction.
Public/ascension preuvesAffiche les preuves et jalons majeurs.
Public/ascension recupererRécupère les objets narratifs déjà enregistrés.
Public/ascension touchesAffiche les raccourcis officiels.
Public/ascension visuelsAffiche la configuration shader et resource pack.
Public/ascension titresOuvre le catalogue des vingt titres.
Public/ascension joursAffiche l’âge mondial détaillé.
Public/ascension jours affichage on|offContrôle les alertes visuelles d’événements.
Public/ascension evenementsAffiche le statut du calendrier mondial.
Public/ascension evenements prochainAnnonce le prochain événement planifié.
Public/ascension rencontre <nom>Invoque une rencontre secrète avec sa clé permanente.
Public/ascension vaelornOuvre les informations et actions liées au combat final.
Opérateur/ascension admin qa statutDiagnostic des systèmes V1.0.0.

Opérateur/ascension admin evenements lancer convergenceLance la Convergence des Royaumes.
Opérateur/ascension admin evenements arreterInterrompt et nettoie l’événement actif.
Opérateur/ascension admin evenements activer|desactiverActive ou désactive le calendrier automatique.
Récupération : les commandes ne fouillent pas les coffres ni les sacs. Vérifie tes rangements avant de recréer un objet narratif.
