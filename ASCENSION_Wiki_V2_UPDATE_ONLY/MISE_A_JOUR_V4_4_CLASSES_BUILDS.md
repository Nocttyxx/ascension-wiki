# ASCENSION Wiki V4.4 — Classes et Builds

## Ajouts

- quatre guides de classes interactifs ;
- forces, faiblesses et statistiques comparées ;
- priorités de progression et familles d’armes recommandées ;
- progression début, milieu et fin de partie ;
- trois builds par classe, soit douze builds ;
- build favori enregistré dans le navigateur ;
- compositeur d’équipe de deux à quatre joueurs ;
- copie du plan personnel ;
- choix de classe relié à `Mon aventure`.

Les builds favoris et la composition testée sont enregistrés sous :

```text
ascension.classGuides.v1
```

La classe choisie dans le wiki ne remplace pas la commande Minecraft :

```text
/ascensionclass
```

Les priorités décrivent une direction de build et non les noms exacts de
tous les nœuds de Passive Skill Trees.
