V1.0.0 officielle

Installer ASCENSION

Le paquet CurseForge officiel est prêt. La page publique sera ajoutée au wiki après validation du projet CurseForge.

Nouvelle installation

  1. Ouvre CurseForge.
  2. Choisis Minecraft puis « Importer ».
  3. Sélectionne le ZIP V1.0.0.
  4. Laisse CurseForge télécharger les références.
  5. Alloue environ 10 Go de RAM.

Serveur existant

  1. Sauvegarde le monde.
  2. Arrête complètement le serveur.
  3. Installe la mise à jour V1.0.0.
  4. Redémarre et vérifie /ascension version.

Pré-requis

Minecraft 1.20.1Forge 47.4.0Java 1710 Go RAM
Publication CurseForge : le lien de téléchargement sera ajouté dès que le projet et son fichier Release seront approuvés.
