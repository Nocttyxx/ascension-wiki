# ASCENSION Wiki V4.3.1 — Portraits Vanilla Fix

Cette mise à jour corrige les quatre cartes Minecraft du Codex des Boss :

- Grand gardien
- Warden
- Wither
- Ender Dragon

Le Codex utilise maintenant la même API que le bestiaire pour charger les
rendus depuis Minecraft Wiki. Une fois une URL chargée avec succès, elle est
mémorisée dans le navigateur avec `localStorage`.

Le logo ASCENSION reste présent comme image de secours lorsque la connexion
ou l’API est indisponible.
